# 《今天也不想上班》动作肉鸽战斗系统 (Combat Roguelike Prototype V1.0)

## 1. 游戏简介
玩家扮演被困在“无限加班公司”里的普通打工人【小陈】，在 8 分钟一局的办公室战斗中，通过移动、闪避、自动攻击、主动技能与“压力值”风险收益机制构筑离谱职场 Build，击败主管并成功打卡下班。

- **核心类型**：俯视角动作肉鸽 + Build构筑 + Boss战
- **首发规模**：1角色（小陈） · 3武器（键盘/杯子/辞职信）+ 3超级进化 · 15项升级 · 8种普通敌人 · 2种精英（HR/项目经理） · 1Boss（主管三阶段） · 8件职场神器 · 5项局外天赋

## 3. 核心玩法与特色系统

### 3.1 压力值系统 (0-100)
- **0-29 (正常)**：正常状态，无额外加成。
- **30-59 (烦躁)**：攻击速度 +8%。
- **60-79 (暴躁)**：攻击速度 +12%，总伤害 +15%。
- **80-99 (我要辞职)**：攻击速度 +18%，总伤害 +30%，暴击率 +12%！
- **100 (崩溃)**：持续4秒，每秒损失 4% 最大生命（无法自然降压，结束后重置为55）。

### 3.2 三大核心武器与超级进化
1. **祖安机械键盘**：
   - 进化条件：`机械键盘 Lv5` + `加班咖啡 Lv3` + `双屏办公 Lv3`
   - 效果：攻速提升28%，双发键帽，命中有18%概率触发“？？？”连锁范围爆炸。
2. **无限续杯**：
   - 进化条件：`马克杯 Lv5` + `工位护盾 Lv3` + `加班咖啡 Lv2`
   - 效果：4个马克杯环绕自身，每8秒产生一次3.2米咖啡冲击波击退普通怪。
3. **辞职报告**：
   - 进化条件：`辞职信 Lv5` + `我不干了 Lv3` + `KPI Lv2`
   - 效果：每2.2秒召唤大型辞职报告砸向敌群中心（180%伤害；压力≥80时范围额外+25%）。

### 3.3 精英与主管Boss战
- **2:40 精英HR**：释放“绩效警告”直线标记，命中降低玩家20%输出，半血召唤邮件怪。
- **4:50 精英项目经理**：周期召唤需求球并生成会议减速圈。
- **8:00 主管Boss**：
  - **P1 (100%-70%)**：文件雨预警 + 扇形进度汇报。
  - **P2 (70%-35%)**：大范围会议区封锁 + 临时需求冲刺 + 汇报连招。
  - **P3 (35%-0%)**：今晚加个班（场景压迫、全速追击、召唤红点消息群）。
  - **通关**：击败主管掉落【下班卡】，拾取后触发 18:00 准点下班结算！

## 4. 运行与部署方式
本游戏采用原生 HTML5 + ES6 模块开发，无需安装任何复杂依赖：
1. **本地运行**：在 `game_project` 目录下通过任意静态服务器打开（例如 VS Code 的 Live Server，或通过 Python 快速启动 `python3 -m http.server 8000`）。
2. **移动端/微信小游戏适配**：已内置虚拟摇杆与触控按键，直接嵌入 WebView 或小游戏适配层即可流畅运行。
